# Keyword Spotting Demo

Interactive demo for the Keyword Spotting (KWS) project.

The demo presents examples of speech corrupted by different noise types and SNR levels, comparing the noisy signal with speech enhanced using the trained enhancement model.

## Main Project

👉 [KWS Project Repository](https://github.com/MayaVB/kws_project)

## What the demo shows

For each example, you can:

- Listen to the clean, noisy, and enhanced speech signals.
- Compare their spectrograms, waveforms, and MFCC representations.
- See the KWS prediction before and after speech enhancement.
- Compare the prediction with the true keyword.

The examples demonstrate how speech enhancement can improve the robustness of the KWS system under noisy conditions.
